# RaenyDesk

Prototipo educativo de acceso remoto para Android, reimplementación limpia desde cero (clean-room), inspirada solo en funcionalidades observables de apps de escritorio remoto.

## Estado del proyecto

- 📄 `docs/RAE_ANALYSIS.md` — Pendiente: requiere el APK de entrada (`./analysis/input/anydesk.apk`) para la Fase 1 (análisis black-box).
- 🏗️ `docs/ARCHITECTURE.md` — Arquitectura propuesta (Fase 2).
- 📱 MVP en Jetpack Compose — Fase 3 (pendiente de aprobación).

## Cómo compilar (cuando exista el código)

```bash
./gradlew assembleDebug
```

El APK se generará en `app/build/outputs/apk/debug/app-debug.apk`.
